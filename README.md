# Data visualization scroll article — working scaffold

This is a research and reading scaffold for a student-led article. The title, thesis, visual design, and final section order are undecided. All prose in `content/` is provisional.

## Run

Open `index.html` in a browser. It uses browser-default HTML and needs no build step, dependency, or local server.

## Project map

- `story/index.html` — separate vertical opening draft for **The Big O**, with the student's title reference and a short provisional introduction.
- `wiki/index.md` — linked, agent-maintained map of sources, measures, experiments, and open checks; see `wiki/AGENTS.md` for the maintenance workflow.
- `content/outline.md` — possible questions and section placeholders, not a fixed narrative.
- `content/draft.md` — original draft labels and prompts, not a finished article.
- `research/sources.md` — source inventory and access status.
- `research/notes/` — separate notes for the editorial reference and seven studies.
- `research/open-questions.md` — unresolved evidence and editorial questions.
- `data/raw/` — small, source-derived CSV extracts, one per study.
- `data/README.md` — data dictionary and caveats.
- `docs/decisions.md` — decisions and agent contributions.
- `experiments/` — separate, unstyled placeholder pages for four Frederick data representations; open `experiments/index.html` from the homepage link.
- `experiments/gallery.html` — local overview of all Processing runs; each run has a navigable image page.
- `experiments/processing-age/` — a separate, wide aligned-interval image test using Gesselman's five adjusted age-band model coefficients; see its README for editable style settings and caveats.

## Research status

Public text was available for the Scientific American reference, Armstrong et al., Gesselman et al., Anderson et al., and Morar-Bolba et al. The student supplied a full Frederick PDF outside the repository. Public copies of Mitchell et al. and McElroy & Perry were found outside their publisher sites; their provenance and limits are documented in `research/sources.md`.

## Before publication

Review the outline and choose the article's question and order. Verify exact wording, denominators, and table values for any chart you decide to design. Obtain lawful full-text access where noted. Keep study populations and measures distinct. The separate visual experiments and story opening are provisional; no animation or charting library has been added.
