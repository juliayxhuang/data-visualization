# The Big O — opening draft

Open `story/index.html` locally. This separate page contains the student's title direction, a 90-word agent-drafted introduction, and a two-step category choice. The existing `index.html`, earlier article text, and experiments are preserved. The generated image reveal, six-group transition, and rest of the scroll story are still to be designed and built.

The title follows the student's supplied reference: “The Big” above a large red O on white. The letter shape is drawn in CSS so it scales with the viewport. At the student's request, the O is smaller with a thinner stroke; the intro type is smaller, its column wider, side padding reduced, and the continue link removed. The visible draft label was removed and the introduction brought closer to the O; draft status remains in the Markdown source. Georgia is a temporary system serif for the live text. The supplied ABC Gramercy files are trial OTF fonts and were not copied into the repository or embedded in the webpage. [Dinamo's licensing terms](https://abcdinamo.com/licenses) distinguish trial evaluation from licensed web use and say desktop OTF files cannot be used for live website text. Replace the fallback when the student chooses an appropriately licensed web font.

The original introduction draft is in `../content/story-intro.md`; the page duplicates it for local preview. Keep both synchronized during revision. No study result or personal prediction is presented in this opening.

The question follows the student's red-on-white reference and uses her original genital drawings with Female and Male labels. Selecting one replaces those options in the same section with her original orientation-symbol drawings: Straight, Bisexual, and Lesbian after Female; Straight, Bisexual, and Gay after Male. A small change control returns to the first pair. The black transparent PNG linework is colored red at display time with an SVG filter; source images are copied into `assets/` without alteration. The question type is smaller as requested. The brief note and expandable source explanation sit between the introduction and the input section, following the student's reference. The explanation is aligned with the introduction and the native disclosure arrow is hidden at the student's request.

Selecting an orientation now reveals an animated, browser-rendered version of the Processing **circular fixed-100** image for the matching Frederick group. One dot is one percentage point; the reported percentage is filled and the remainder is outlined. Each dot enters separately, with no animation under reduced-motion settings. The six values, sample sizes, and colors mirror `../data/raw/frederick-2018.csv` and `../experiments/processing-frederick/FrederickSeries/output/run-20261106-142959/settings.csv`; the original PNG is linked from each result. This is a reversible visual prototype, not a personal prediction. “Change answer” returns to the first choice, and the orientation options remain available for comparing groups.

The choice heading is smaller. Choice labels appear on hover or keyboard focus, and remain visible on touch devices. The result now places the ring beside the two selected illustrations. Clones of the original SVG-wrapped PNGs enter the side panel with a short translation; reduced-motion settings disable the entrance. No animation library is used.

Frederick et al. reported six gender/orientation groups, but did not provide the exact wording of the survey's sex or gender question or results for every identity. GSAP research is recorded in `../docs/gsap-notes.md`; no animation dependency has been added.
